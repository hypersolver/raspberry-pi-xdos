# XDOS XAPP 桌面捷徑與圖示規格

[English](xapp-desktop-spec.md) · [Arduino XAPP 開發與部署](arduino-xapp.zh-TW.md)

本規格適用於啟用動態捷徑的 APPSCAN 系列。舊版 PXLAYOUT Release 使用固定捷徑。

## 搜尋與顯示上限

1. FAT32 開機分割區掛載後，掃描 `SD:/XDOS/APPS/` 的第一層。副檔名 `.APP` 不分大小寫。
2. 依 FAT 目錄讀取順序收錄前 **10** 個有效清單，不做字母排序。子目錄、無效清單與執行檔缺失的項目會略過，不占名額。收錄第 10 個後即停止掃描。
3. 更新卡上的清單後，重新開機會重新掃描。執行檔的實際 ABI 與適用的核心指紋由 XAPP Loader 在啟動時驗證。

## .APP 清單

將下例存為 `ARDDEMO.APP`，並將對應的 `ARDDEMO.XAPP` 放在指定路徑。

```ini
[Application]
Name=Arduino Demo
Exec=SD:/XDOS/APPS/ARDDEMO.XAPP
ABI=1
Arch=armv7-a32
Type=Arduino
```

| 欄位 | 規定 |
| --- | --- |
| `[Application]` | 節名與欄位名區分大小寫。清單為 1–1024 bytes 的純文字，支援 LF 或 CRLF。建議使用 ASCII、無 BOM。 |
| `Name=` | 必填、不可為空，用於桌面名稱和圖示。 |
| `Exec=` | 必填。指定 `SD:/XDOS/APPS/` 或 `SD:/XDOS/INBOX/` 第一層的現有 `.XAPP` 檔案。主檔名可用英文字母、數字、底線與連字號。 |
| `ABI=`、`Arch=` | 目前分別為 `1` 和 `armv7-a32`。 |
| `Type=Arduino` | Arduino 草稿使用此欄位以取得 XDOS 的草稿生命週期 API，執行檔須與核心指紋配對。 |
| `Icon=` | 動態桌面由 `Name=` 產生圖示。舊清單中的此欄位可保留。 |

## 版面、文字與點擊

- 固定上下兩排，每排五格。每排水平等距，兩排平均分布在桌面可用區域。依序填完上排再填下排，空位留空。
- 方形圖示與名稱共用格子的水平中心線。名稱置中於圖示下方。**1–16 個可顯示字元**可顯示，空格計入。若放不下放大字體，改用一般字體。一般字體也放不下，或名稱達 **17 個字元**時，隱藏整行名稱。
- 現有像素字型支援 ASCII 可印字元。其他位元組顯示為 `?`，所以 Unicode 名稱的長度以替換後的顯示文字計算。
- 點圖示或名稱都可啟動，名稱隱藏時也可點圖示。

## 字母與色票

## 驗證基準

Pi 3B+ 的 MultiCore APPSCAN QA3 於 1920×1080 實測。UART 回報 11 個清單只載入 10 個。HDMI 確認上下各五個、`CENTERED LABEL16` 置中、第 11 個未顯示，以及 17 字元名稱隱藏後仍可點圖示開啟。
