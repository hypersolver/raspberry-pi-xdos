# Raspberry Pi XDOS

[繁體中文](README.md) · [Download Pixel BBS Layout](https://github.com/hypersolver/raspberry-pi-xdos/releases/tag/v0.6.2-rc3-xapp6-pxlayout)

XDOS is an ARM32 bare-metal desktop for Raspberry Pi. Circle provides the hardware support, LVGL draws the desktop, and the system loads external XAPPs from microSD. The current public prerelease, PXLAYOUT, was tested on a Raspberry Pi 3B+ at 1280×720 and 1920×1080.

PXLAYOUT introduces the Pixel BBS desktop and boot splash, resolution-aware shortcuts, and an SD-based H.264 MP4 player. Its core image is 1,491,628 bytes. Download the matching XAPPs and SHA-256 manifest from the same Release.

Documentation and source are maintained on main. Release tags identify published builds.
